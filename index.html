BreezeLab

BreezeLab develops observation-comparable LES cases and differentiable cloud-physics workflows with Breeze for PRECISION/GENESIS.

The Eastern North Atlantic example builds a simulation, runs it, and plots its saved cloud-water and rain diagnostics. This page is generated by executing cases/eastern_north_atlantic.jl with Literate, then building the manual with Documenter. The figures come from that execution.

The exported eastern_north_atlantic constructor builds the public Covert configuration without running it. For official LASSO inputs, use ena_simulation with the corresponding protocol; see ENA experiment definitions.

SEA STARR and TRACER-MIP currently have case specifications and input manifests; their simulation adapters are not implemented yet.

Build this manual

From the repository root with Julia 1.12:

julia --project -e 'using Pkg; Pkg.instantiate()'
julia data_wrangling/fetch_covert_inputs.jl
julia docs/setup.jl
julia --project=docs docs/make.jl

The default build executes the six-hour ENA example on an NVIDIA GPU. On wpcluster, use an allocated H100 or A100. Open docs/build/index.html after completion. There is no GPU CI or automatic publication yet.

For a short CPU check of the execution, analysis, and rendering workflow:

julia --project=docs docs/make.jl --smoke

The smoke build uses an 8×8×24 grid for four simulated seconds and labels its pages accordingly. Its output is not a physical ENA result. Both modes rebuild the example and overwrite docs/build/; output and provenance remain under output/documentation/ena/ (or output/documentation/ena_smoke/). Only the figure is copied into the manual. Generated pages, output, and the derived documentation environment are ignored by Git. docs/setup.jl preserves the simulation dependency versions in the repository manifest when adding Documenter and Literate.
